# Лабораторная работа №2: Метод Баланса (Смешанная краевая задача, Вариант 2)

Этот проект представляет собой численное решение краевой задачи для ОДУ 2-го порядка (стационарное уравнение теплопроводности) с разрывными коэффициентами. Программа реализует метод баланса (интегрально-интерполяционный метод) и поддерживает как классические условия Дирихле, так и смешанные граничные условия (теплообмен).

## 📁 Структура проекта и назначение файлов

### Ядро на C++ (вычислительная часть)
*   **`Problem.h` / `Problem.cpp`** — Описание задачи. Здесь задаются коэффициенты \(k(x), q(x), f(x)\), точка разрыва \(\xi=0.25\), параметры \(\alpha\) и \(u_{cp}\) для смешанной задачи, а также тип граничных условий.
*   **`Quadrature.h` / `Quadrature.cpp`** — Модуль численного интегрирования. Использует адаптивную квадратуру Гаусса для вычисления интегралов \(\int \frac{1}{k} dx\), \(\int q dx\) и \(\int f dx\). Умеет корректно разбивать интеграл в точке разрыва \(\xi\).
*   **`Progonka.h` / `Progonka.cpp`** — Реализация метода прогонки (алгоритма Томаса) для решения системы линейных уравнений с трехдиагональной матрицей за \(O(n)\) операций.
*   **`DifferenceScheme.h` / `DifferenceScheme.cpp`** — Сборка разностной схемы (матрицы) и вызов прогонки. Здесь реализована логика метода баланса (интегрально-интерполяционного метода). Отдельно обрабатываются внутренние узлы и правый край (в зависимости от выбранного типа задачи: Дирихле, Смешанная-классика или Смешанная-улучшенная).
*   **`AnalyticSolution.h` / `AnalyticSolution.cpp`** — Аналитическое решение для тестовой задачи (где коэффициенты кусочно-постоянны). Решает систему \(4\times4\) для нахождения констант \(C_1..C_4\) с учетом условий сопряжения и граничных условий.
*   **`main.cpp`** — Точка входа. Принимает аргументы командной строки (размер сетки \(n\) или флаг автоподбора, тип задачи), запускает расчет, выводит справку в консоль и сохраняет результаты в `results/result.csv`.

### Интерфейс на Python (GUI)
*   **`solver_gui.py`** — Графическая оболочка на `tkinter` + `matplotlib`. Позволяет выбирать тип задачи, задавать точность \(\varepsilon\), запускать C++ программу, а затем читает созданный `result.csv` и рисует графики (решения и погрешности) и выводит таблицу.

## 🧠 В чем суть методов

### Метод баланса (интегрально-интерполяционный)
Вместо того чтобы аппроксимировать дифференциальное уравнение в каждой точке (как в методе конечных разностей), мы интегрируем уравнение теплопроводности по каждой ячейке сетки \([x_{i-0.5}, x_{i+0.5}]\).
Это гарантирует **закон сохранения энергии** (консервативность). В результате для каждого узла получается уравнение, связывающее его с соседями:
\[
 -a_i v_{i-1} + (a_i + a_{i+1} + d_i h^2) v_i - a_{i+1} v_{i+1} = f_i h^2
\]
где коэффициенты \(a_i, d_i, f_i\) вычисляются через интегралы от \(1/k, q, f\).

### Классическая vs Улучшенная аппроксимация (Смешанная задача)
У нас на правом конце задано условие теплообмена: \(-k(1)u'(1) = \alpha(u(1) - u_{cp})\).
*   **Классическая (3-й человек):** Производная \(u'(1)\) берется как левая разность \((v_n - v_{n-1})/h\). Дает 1-й порядок точности на границе (общая сходимость падает).
*   **Улучшенная (4-й человек):** Применяется интегральный баланс к половинной ячейке. Поток на границе выражается точнее, что сохраняет общую сходимость **2-го порядка** \(O(h^2)\) на всей области.
